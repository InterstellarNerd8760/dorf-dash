# Dorf Dash

Cash-only lunch fetch for SF Waldorf High School. Not DoorDash.

**Live site is Grok Build.** This repo is the backup / GitHub Pages copy.

- `index.html` — page shell (West Portal + Stonestown)
- `app.js` — menus, caps, copy-to-clipboard. `BUILTIN_HOOK` stays empty on purpose.
- `gnome.jpg` — Imagine running gnome
- `favicon.svg` — gnome-hat tab icon

The Discord webhook is **not** in this repo. The live Grok Build app posts orders from its server so school computers that block discord.com still work, and so the URL never shows up in GitHub or View Source.

Prices in `app.js` are Sept 2026 in-store research (not delivery markup). Friends are photographing paper menus next; swap numbers in `MENU` when those land.
