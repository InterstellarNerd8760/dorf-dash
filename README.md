# Dorf Dash

Tiny SFWHS lunch-run storefront. Cash only. Joke on purpose.

Live once GitHub Pages is on: https://interstellarnerd8760.github.io/dorf-dash/

## Turn Pages on (one time)
Repo → Settings → Pages → Deploy from branch → `main` / `/ (root)`.

## grok.me
This chat cannot press Grok Build's Publish button. If you want `dorf-dash.grok.me`, open Grok **Build Mode**, paste this `index.html`, hit Publish.

## What it does
Menu + reserve form. Copies a Discord-ready order. Does not charge cards. Does not buy food by itself.
